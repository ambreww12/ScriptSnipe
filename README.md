# ScriptSnipe

Aggressive subscription killer.

Find every recurring charge, rank them by real value, and cancel the ones wasting your money.

## Local preview

Just open `index.html` in a browser, or run a simple static server:

```bash
npx serve .
```

## Stack

- Plain HTML / CSS / JS (no framework yet)
- Ready for GitHub Pages or any static host
